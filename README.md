# Wikidata 14th Birthday Presentation Prishtina

reveal.js slides (~10 min) for the Wikidata 14th birthday event in Prishtina, by Wikimedians of Albanian Language User Group. Open `index.html` (Albanian) or `index.en.html` (English) in a browser; press `S` for speaker notes.

The applications section shows Query Service, Reasonator, Histropedia, Inventaire and Monumental. Screenshots are in `img/`; the Histropedia and Inventaire images come from Wikimedia Commons (CC BY-SA 3.0 and CC0) and are credited on their slides.
